# /plan — Create Execution Plan

Break a phase or step into detailed, actionable sessions.

## Input
$ARGUMENTS — phase or step identifier (e.g., "phase1", "step 2.4", "processing pipeline")

## Steps

1. **Read planning skill**: `.agents/skills/plan-creator/skill.md`
2. **Read skill mapping**: `.agents/skills/skill-mapping/skill.md`
3. **Follow workflow**: `.agents/workflows/create-plan.md`
4. **Save output**: `tasks/plans/{phase}-execution-plan.md`
5. **Create action guides**: for first 1-2 sessions using `.agents/workflows/create-action-guide.md`
6. **Update tracking**: `tasks/progress.md` and `.context/session-handoff.md`
