# /session-start — Begin Work Session

Read current state and plan the session.

## Steps

1. **Read session state**: `.context/session-handoff.md`
   - Last session number, agent
   - Build/test status
   - Pending items

2. **Read agent notes**: `.context/agent-notes.md`
   - Learned rules (avoid repeating mistakes)
   - Progress counts

3. **Identify next work**:
   - Read `tasks/08-master-plan.md` → Session Plan table
   - Find current session by checking progress
   - Read action guide if referenced in handoff

4. **Read mandatory skills**: Check session description for skill requirements

5. **Plan session**: Output 2-4 items to accomplish

6. **State plan** before starting any code
